The Risk: If a researcher is monitoring state-level feeds and forgets to scope a "signed into law" item, it will be ingested as a Federal statute. While filterable, the default behavior favors Federal scope, which could lead to significant manual cleanup for state-centric research batches.1
2. Silent Error Conditions
.htaccess Failure on Nginx:
The Issue: ws_feed_monitor_ensure_data_dir() writes a "Deny from all" .htaccess file to protect wp-content/uploads/ws-feed-data/.1
Silent Failure: Nginx servers ignore .htaccess files. Unless the operator manually adds a server-level block, your staged research JSON (which may contain sensitive draft legislation or internal notes) is publicly accessible via a direct URL.13
Query Layer Transient Expiration:
The Issue: WS_CACHE_LEGAL_UPDATES_SITEWIDE has a TTL of 1 hour.4
Silent Failure: If the site experiences a traffic surge and the cache expires, multiple concurrent requests will bypass the cache and hit the database for 100 posts simultaneously. This can cause a "cache stampede" that degrades performance without triggering a formal error log.4
Missing Non-Main-Query Guards in render-agency.php:
The Issue: ws_handle_agency_render guards against non-main queries but uses a static $is_rendering flag to prevent infinite loops from do_shortcode.5
Silent Failure: If another plugin uses the_content filter to inject an agency post into a different page (e.g., a "featured agency" block), your renderer will return the original content without procedures because it isn't the "main query".5
3. Weak Docblocks & Documentation Gaps
query-directory.php Load Order:
Status: Critical. The file notes it must load after query-shared.php.6
Weakness: It does not explain the dependency. A developer might move the load order in loader.php to "clean up" the file list and inadvertently break the directory dataset because ws_q_build_assist_org_row relies on sub-array builders in the shared file.67
WS_FEED_MAX_ITEMS Const documentation:
Status: Vague. It is defined as "Max items to fetch per poll" (currently 50).1
Weakness: It does not document if this is a limit imposed by the Inoreader API or a safety cap for PHP memory. If a heavy legislative day occurs with > 50 results, the system will silently drop the overflow until the next daily poll.1
Agency Procedure "Both" Type Label:
Status: Outdated. The label is "Disclosure & Retaliation Procedure".5
Weakness: The documentation doesn't specify if this type is for procedures that require both or allow both. This ambiguity can lead to researchers mis-categorizing procedures that have different legal requirements.5

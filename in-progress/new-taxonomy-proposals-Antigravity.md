# Proposed Taxonomy Terms (Antigravity)

The following are the terms originally suggested for the newly created taxonomies. While we have restored the legacy terms to ensure full data parity with the existing `ws-core` system, these terms are documented here for future consideration.

If any of these categories appear useful or if they cover gaps in the current taxonomy definitions, they can be introduced in a future version.

## Fee Shifting Rules (`ws_fee_shifting_rule`)
*   `mandatory-plaintiff` (Mandatory for Prevailing Plaintiff)
*   `discretionary-plaintiff` (Discretionary for Prevailing Plaintiff)
*   `defendant-bad-faith` (Defendant - Only if Bad Faith/Frivolous)
*   `two-way` (Two-Way - Prevailing Party)
*   `silent` (Silent / Not Specified)

## Employer Defenses (`ws_employer_defense`)

*   `preponderance` (Preponderance of Evidence)
*   `same-action-defense` (Same Action Defense)
*   `bona-fide-error` (Bona Fide Error)
*   `reasonable-factor` (Reasonable Factor Other Than Protected Activity)

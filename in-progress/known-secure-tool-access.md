Directory / hosted tip-line app: https://tips.hushline.app/

Entity: Science & Design, Inc. dba Hush Line.

Status: not an assist organization. Treat as secure-tool / platform infrastructure.

Useful facts:
- U.S. 501(c)(3) nonprofit.
- EIN: 92-0421940.
- Provides open-source anonymous reporting / whistleblower tip-line tooling.
- Supports verified accounts for organizations and individuals.
- Supports Tor access and Onion-native workflows.
- Uses OpenPGP.js for client-side message encryption when a recipient public key is configured.
- Allows indirect two-way communication when the submitter provides contact information or uses a Hush Line account.
